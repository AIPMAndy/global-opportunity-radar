# 数据与研究方法 · Global Opportunity Radar

## 一、核心原则

网站将三个层次分开：

1. **观察**：在不同城市、市场看到的商业现象。可以提出问题，但不是经济统计。
2. **证据**：官方宏观数据、公开项目和产品发布，保留来源、时间及检索口径。
3. **决策**：真正可做的生意仍需验证客户是谁、是否有预算、能否形成可持续收入。

增长率高不意味着利润率高，AI 论文多不意味着技术已进入企业采购，发布项目多不意味着公司盈利。

## 二、五个宏观指标

所有经济指标来自 World Bank World Development Indicators（WDI）开放 API。

| 页面指标 | WDI 指标代码 | 单位 | 说明 |
| --- | --- | --- | --- |
| GDP 年增长率 | NY.GDP.MKTP.KD.ZG | % | GDP 实际增长率 |
| 消费价格通胀 | FP.CPI.TOTL.ZG | % | CPI 年变化 |
| 失业率 | SL.UEM.TOTL.ZS | % | 总劳动力的失业比例，ILO 模型估算 |
| 外资净流入 / GDP | BX.KLT.DINV.WD.GD.ZS | % | FDI 净流入占 GDP 的比例 |
| 人均 GDP | NY.GDP.PCAP.CD | 当前美元 | 现价美元计算，不是购买力平价 |

原始文档：https://data.worldbank.org/

### 统计年份与抓取时间

每项宏观数据各自展示统计年份；不同国家、不同指标可能来自不同年份。系统默认寻找官方最近可用的值。

页面顶部的抓取时间仅表示程序最后一次执行的时间，不能表示经济数据每六小时变化。

### 历史曲线与可比性（V2.1）

- WDI GDP 实际增长率接口收集约 10 年的年度观察值，存放在 snapshot.json 的 history 字段。
- 只展示真实返回年份：缺失年份不插值，折线会断开。
- 榜单默认展示各经济体最近可用数据，其年份未必一致，比较前须核对最后一列。
- CSV 包含经济体、指标、数值、单位、统计年份和世界银行来源链接。
- 不计算主观“创业机会评分”。

遇到缺失值：保留空值，不用 0 代替。国家或经济体有 GDP 数据但缺少其他指标时，只显示已获取的指标。

## 三、AI 发展信号

### 1. OpenAlex

接口：https://api.openalex.org/works

- 检索关键词：artificial intelligence。
- 时间：上一自然月。
- 展示：索引记录中匹配关键词的论文数。
- 不把匹配数解释成全球全部 AI 论文，也不把它等同于技术突破。

### 2. GitHub

接口：https://api.github.com/search/repositories

- 查询：topic:ai-agents，并限定创建日期为最近 30 天。
- 按 Star 数排序，展示符合检索条件的开源仓库。
- 一个公开仓库不等于一家创业公司；主题标签取决于维护者。

## 四、创业产品发布信号

Hacker News Algolia：https://hn.algolia.com/api

- 查询条件：tags=show_hn，query=AI。
- 展示最新检索结果及原始链接。
- 这是开发者社区公开发布的产品和项目，不代表融资成功、客户数量或收入。

下一步可增加专业创业融资来源，但每条融资信息至少应保留：公司名称、融资轮次、公开金额、公告日期、币种和原始报道链接。

## 五、地图数据

V2 的世界海岸轮廓来自公共 GitHub 项目 [johan/world.geo.json](https://github.com/johan/world.geo.json) 的国家 GeoJSON，并对坐标作了简化以便静态网页离线加载。

原始世界地图资料及衍生许可请参考该数据集原仓库。本项目对地图轮廓作简化用于视觉展示，地图不用于领土边界法律认定或精密导航。地图上 25 个定位光点与 World Bank WDI 的经济体指标列表分开管理。

地图轮廓部署于 data/world.json，无需运行时请求第三方地图 SDK。

## 六、数据处理链路

    World Bank / OpenAlex / GitHub / Hacker News
                          ↓
              scripts/collect.py
               并发请求、校验、归档
                          ↓
               data/snapshot.json
                          ↓
             GitHub Pages 静态部署
                          ↓
            app.js / explorer.js 展示数据

数据源失败时，快照里记录 sources 下相应来源的 ok=false 与错误信息，展示层不把错误响应当成数值。

## 七、更新与扩展

想新增数据源，需要明确以下字段：

- 来源是否公开、可访问？
- 统计对象、地理口径、时间窗口是什么？
- 更新时间和事件发生时间如何区分？
- 是否可以提供可点击的原始链接？
- 缺失/限流/撤稿时怎样展示？
- 该指标和创业成功之间究竟是什么关系？

建议优先补充历史序列、行业数字化采购、招聘需求、创业融资原始公告，再做所谓的综合「机会评分」。

在数据不完整之前，项目提供的是研究和比较工具，而不是确定性的国家投资排序。
