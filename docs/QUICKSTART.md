# 5 分钟上手｜全球机会雷达

在线网站：https://aipmandy.github.io/global-opportunity-radar/

这是免费开源的全球经济、AI 与创业信号观察站。所有经济指标保留统计年份。

## 1. 旋转地球，先看几个市场

打开网站，点击美国、越南、中国内地、中国香港。右侧展示 GDP 增长、通胀、失业率、外资净流入占比和人均 GDP。每项数据都标了年份；— 代表暂无数据。

## 2. 打开「市场对比」

切换 GDP、FDI、失业率或人均 GDP；再用「全部区域」选择东南亚等地区，查看指标排序。排序中的国家可能属于不同统计年份，先核对行尾年份再做结论。

## 3. 把时间拉长

GDP 历史趋势默认对比美国、越南、中国内地、中国香港。可以移除其中一个，再添加其他经济体（最多 5 个）。曲线仅使用世界银行真实发布的年度观察值，缺失年份会断线。

## 4. 把宏观差异转成创业研究问题

- 美国：AI 的技术投入由哪些企业持续采购？
- 越南：外资流入如何带来本地物流、软件或服务预算？
- 中国内地：谁会为可量化的降本增效持续付费？
- 中国香港：国际交易与专业服务中哪种需求可重复成交？

这些问题是研究假设。需要结合访谈、预算和客户交易验证。

## 5. 导出、复核

点击「下载 25 个经济体 CSV 数据」，可以得到经济体、五项指标、数值、单位、年份及原始链接。文件采用 UTF-8 BOM 方便 Excel 打开。

AI 研究来自 OpenAlex 关键词检索，开源仓库来自 GitHub ai-agents 主题，产品发布来自 Hacker News Show HN。它们都不能直接当作融资收入或创业成功数量。

## 保姆级自建

Fork 仓库，在 Settings → Pages 的 Source 选择 GitHub Actions，然后到 Actions 运行 Build and Publish Global Opportunity Radar。项目不需要服务器或 npm 依赖。

本地运行：

    python3 -m http.server 8000

首次联网采集：

    python3 scripts/collect.py
